## 展場動線重建

科教館的特展把場地切成好幾個展區。展區之間用岔路串起來：從某個展區出發，最多只會有**一條左岔**和**一條右岔**通往下一個展區，走進岔路後裡面同樣是這種規則，沒有岔路就是走到底了。所有隊伍都從同一個入口展區出發。

同一場特展由三位導覽員各帶一隊走完全程，他們在每個展區都會打卡，但打卡的時機習慣不同：

| 導覽員 | 到了一個展區以後的順序 |
|--------|------------------------|
| 甲 | 先在這個展區打卡 → 走完左岔那一整區 → 走完右岔那一整區 |
| 乙 | 先走完左岔那一整區 → 回到這個展區打卡 → 走完右岔那一整區 |
| 丙 | 先走完左岔那一整區 → 再走完右岔那一整區 → 最後才回到這個展區打卡 |

活動結束後，主辦單位只保留了**其中兩位**導覽員的打卡序，第三位的紀錄不見了。請寫程式把它還原出來。

### 還原規則

1. **模式 1**：給你甲和乙的打卡序，請輸出**丙**的打卡序。
2. **模式 2**：給你乙和丙的打卡序，請輸出**甲**的打卡序。
3. 每一組資料自帶模式標記，同一筆測資裡可能兩種模式都出現，請逐組判讀。
4. 展區編號是 `1` 到 `n` 的一種排列，編號大小和位置**沒有任何關係**（不要假設哪一串會是排好序的）。
5. 兩位導覽員的紀錄一定來自同一場特展，還原結果唯一。

### 輸入說明

- 第一行：整數 `T`（`T >= 1`），表示這一筆有幾組資料
- 每組資料共三行：
  - 第一行：兩個整數 `M n`——`M` 是模式（`1` 或 `2`），`n` 是展區數（`1 <= n <= 1500`）
  - 第二行：`n` 個整數——`M = 1` 時是**甲**的打卡序，`M = 2` 時是**乙**的打卡序
  - 第三行：`n` 個整數——`M = 1` 時是**乙**的打卡序，`M = 2` 時是**丙**的打卡序
- 同一行的整數以單一空白隔開
- 從入口展區往下數，動線最深不超過 300 層

### 輸出說明

- 每組資料輸出一行：`n` 個展區編號，以單一空白隔開
- `M = 1` 輸出丙的打卡序；`M = 2` 輸出甲的打卡序

### 範例

**輸入：**

```
1
1 7
2 1 5 3 6 4 7
3 5 1 6 2 7 4
```

**輸出：**

```
3 5 6 1 7 4 2
```

範例說明：甲第一個打卡的是 `2`，代表 `2` 就是入口展區；在乙的紀錄裡 `2` 左邊的 `3 5 1 6` 都在左岔那一區、右邊的 `7 4` 都在右岔那一區。照這個方式一層一層分下去，就能拼出丙的打卡序。

模式 2 的例子：

**輸入：**

```
1
2 7
6 1 2 4 3 5 7
6 1 4 2 5 7 3
```

**輸出：**

```
3 2 1 6 4 7 5
```

範例說明：丙**最後**才在入口展區打卡，所以 `3` 是入口展區；在乙的紀錄裡 `3` 左邊的 `6 1 2 4` 在左岔那一區、右邊的 `5 7` 在右岔那一區。接下來要怎麼往下拆，請自己想清楚——模式 2 不是把模式 1 的程式原封不動套上去就會對。
