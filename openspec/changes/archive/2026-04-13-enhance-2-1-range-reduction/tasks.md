````markdown
### range 的三種寫法，其實是同一招

到這裡你已經學了三種 `range` 的寫法，看起來像三個不同的工具。但事實上，range 只有一種完整形式：

**`range(start, stop, step)`**

其他兩種，只是 Python 幫你「省略常用預設值」的簡寫。怎麼省的？一步一步來看。

**第一步：省略 step**

你有沒有發現，大部分的情況下 step 都是 1？每次都寫 `, 1` 太囉嗦了，所以 Python 說：「step 不寫，我就當作是 1。」

```python
range(3, 7)    # 其實是 range(3, 7, 1) → 產生 3, 4, 5, 6
```

**第二步：再省略 start**

同樣的道理，最常見的起點是 0。所以 Python 再幫你一次：「start 也不寫，我就從 0 開始。」

```python
range(5)       # 其實是 range(0, 5, 1) → 產生 0, 1, 2, 3, 4
```

整理一下這個省略鏈：

```
range(start, stop, step)   ← 完整版
      │
      │ 省略 step → 預設為 1
      ▼
range(start, stop)         ← 少寫一個參數
      │
      │ 省略 start → 預設為 0
      ▼
range(stop)                ← 最精簡的寫法
```

所以下次看到 `range(10)`，你可以自動展開成 `range(0, 10, 1)`：從 0 開始，到 10 之前停下，每次加 1。掌握了這個「展開」的思路，就不用死記三種寫法了 ᕦ(ò_óˇ)ᕤ

說到展開，你可能已經注意到 range 產生的數列有一個熟悉的規律：

> [!TIP] 📌 數學小彩蛋
> 仔細看 `range(0, 10, 2)` 產生的 `0, 2, 4, 6, 8`，有沒有覺得很眼熟？
>
> 沒錯，這就是數學課的**等差數列**：首項 0、公差 2。
>
> 事實上，Python 官方文件就是這樣定義 range 的："It generates arithmetic progressions."（它會產生等差數列。）
>
> `start` 就是首項 a₁，`step` 就是公差 d。下次數學課碰到等差數列，你可以偷偷用 Python 驗算 (´∀`)
````
