# Python 自學

歡迎來到 Python 自學課程。本課程以 108 課綱核心素養為基礎，透過「輸入 → 處理 → 輸出」的 Judge 解題思維，培養解決問題的演算法邏輯。

## 課程模組

| 模組 | 主題 | 內容 |
|------|------|------|
| 模組一 | 與電腦溝通的基礎 | 環境安裝、變數與型別、流程控制 |
| 模組二 | 整理與征服大資料 | 迴圈、串列、排序、字典 |
| 模組三 | 抽象化與工具封裝 | 函數、二分搜尋、遞迴 |
| 模組四 | APCS 進階軍火庫 | 語法糖、位元魔法、內建神兵 |
