## 校刊排版檢查器

復興高中校刊社用純文字排版系統寫稿：稿件裡除了一般文字，還夾雜三種成對的排版標記——圓括號 `()` 標旁註、方括號 `[]` 標注音、大括號 `{}` 標版面指令。標記可以巢狀，但必須正確配對：每個右標記要與「最近一個尚未配對的左標記」同種配對。

主編要你寫一支「排版檢查器」：對每行稿件，找出**第一個無法配對的標記字元**，回報它是第幾個字元（從 1 開始數；稿件裡的每個字元——包括一般文字——都要計位），讓編輯能直接跳到該處修稿。整行都正確配對時回報 0。

### 任務說明

由左至右掃描稿件行，依下列規則回報：

1. 遇到右標記時，若目前沒有任何尚未配對的左標記，或最近一個尚未配對的左標記與它不同種——這個右標記就是第一個無法配對的字元，回報它的位置。
2. 掃描結束後，若仍有左標記沒有配對成功，回報**最早出現**的那個未配對左標記的位置。
3. 若以上皆未發生，回報 0。

例如 `x([y)z]`：第 5 個字元 `)` 出現時，最近尚未配對的左標記是 `[`，不同種——回報 5。又如 `((a`：兩個 `(` 到行末都沒配對，最早的在第 1 個字元——回報 1。

### 輸入說明

- 第一行：整數 T，代表稿件行數（1 ≤ T ≤ 5）
- 接下來 T 行：每行一個稿件字串（長度 1 ~ 62000），只包含小寫字母、數字、`.,;` 與 `()[]{}`

### 輸出說明

- 輸出 T 行：第 i 行為第 i 行稿件的回報位置（一個整數；全部正確配對時為 0）

> 提醒：部分測資的稿件行長達上萬字元。經實測，「每遇到一個右標記，就用迴圈逐字元往回重新掃描」的寫法會超出運算次數限制、無法完成這些測資。

### 範例

**輸入：**

```
3
a(b)c.
(x(y)
)(
```

**輸出：**

```
0
1
1
```

第一行：唯一一組 `()` 正確配對——回報 0。第二行：第 3 個字元的 `(` 與第 5 個字元的 `)` 配對，但第 1 個字元的 `(` 直到行末都沒配對——回報 1。第三行：第 1 個字元 `)` 出現時沒有任何左標記可配——回報 1。
