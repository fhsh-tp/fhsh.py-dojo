## 跑馬燈顯示計數

社團在活動中心走廊掛了一面活動看板：由左到右一整排 `n` 格燈。每一格只有兩種樣子——**亮**或**暗**；整面看板呈現出來的樣子（哪些格是亮的、哪些格是暗的）就叫做一個**畫面**。只要有任何一格的亮暗不同，就算是兩個不同的畫面。

期末盤點時，社長發現這 `n` 格裡面有 `k` 格的燈泡燒壞了。燒壞的那幾格不管怎麼接線都只會是暗的，其餘的格子則可以自己決定要亮還是要暗。

社長想知道：燈泡壞成這樣以後，這面看板總共還能顯示出**幾種不同的畫面**？

### 輸入說明

- 一行兩個整數 `n` 與 `k`，中間以一個空白隔開
  - `1 <= n <= 1000000`：看板的格數
  - `0 <= k <= n`：燒壞的格數

### 輸出說明

- 輸出一行整數：這面看板能顯示的畫面種數。

這個數字可能非常大，所以請不要直接輸出它本身，而是輸出**它除以 `1000000007` 之後的餘數**。

### 範例

**輸入：**

```
5 2
```

**輸出：**

```
8
```

### 範例說明

看板有 5 格，其中 2 格燒壞了。先把這兩類格子分開來看：

1. **燒壞的 2 格**：永遠都是暗的，沒有任何選擇的餘地，這 2 格湊出來的樣子從頭到尾只有一種。
2. **還能動的 3 格**：每一格都可以自己決定亮或暗。

接著把還能動的 3 格一格一格決定下去：

- 第 1 格還能動 → 亮或暗，有 2 種決定
- 第 2 格還能動 → 不管第 1 格怎麼決定，它自己一樣有 2 種決定
- 第 3 格還能動 → 同樣有 2 種決定

三格的決定互不影響，而且只要有一格決定得不一樣，做出來的畫面就不一樣。所以能做出來的畫面共有

```
2 × 2 × 2 = 8
```

種。8 比 `1000000007` 還小，除下去的餘數就是它自己，因此輸出 `8`。

### 邊界情況

- `k` 可以是 `0`：表示燈泡全部都是好的，`n` 格都能自己決定亮暗。
- `k` 也可以等於 `n`：表示整面看板的燈泡全部燒壞，看板只能呈現「整面全暗」這唯一一種畫面，答案是 `1`。
